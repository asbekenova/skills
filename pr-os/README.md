# PR_OS в репозитории skills

Ветка `pr-os` форка vercel-labs/skills. Код CLI в корне остаётся как в оригинале, наша часть лежит здесь.

| Папка | Что внутри |
|---|---|
| `kit/` | Монтажный набор: `brand.css` (цвета, шрифты, бумага, безопасная зона), `ease.js` (анимационные хелперы), `template.html` (сцена с render(t)), `render.mjs` (кадры → mp4) |
| `library/` | Сохранённые тесты и перебивки, `INDEX.md` с оценками |
| `radar/` | `PROTOCOL.md`: что радары делают с репозиторием; `skills-log.md`: журнал предложенных скиллов |
| `../.claude/skills/` | Одобренные скиллы, установленные через CLI (подхватываются в сессиях, где подключён репозиторий) |

## Быстрый старт

```bash
cd pr-os/kit && npm i
cd .. && node kit/render.mjs library/000-demo/scene.html --preview   # ключевые кадры с рамкой безопасной зоны
node kit/render.mjs library/000-demo/scene.html                      # mp4 1080×1920, 30 fps
```

## Как одобрить скилл от радара

Радар присылает ссылку вида `.../compare/pr-os...radar/skill-...`. Откройте её, посмотрите файлы, нажмите «Create pull request», затем «Merge». Чтобы отклонить, просто не сливайте ветку и напишите причину в `radar/skills-log.md`.
